Orchestration Layer

Receives ML incidents, validates the payload, and broadcasts accepted incidents to connected clients.

/alert POST

ML service submits one incident.

/handshake WS

Client subscribes to incident broadcasts.

/healthz GET

Deployment health check.

POST /alert

Input: incident JSON. Output: 202 JSON or error text.

Request body

{
  "incident_id": "string",
  "type": "animal_on_road | person_on_road | stopped_vehicle | road_obstruction | unknown",
  "occurred_at": "ISO-8601 timestamp",
  "reported_at": "ISO-8601 timestamp",
  "location": {
    "latitude": 37.7749,
    "longitude": -122.4194,
    "road_name": "string | null",
    "direction": "string | null",
    "mile_marker": "string | null",
    "camera_id": "string"
  },
  "recommended_action": {
    "priority": "low | medium | high | critical",
    "message": "string"
  },
  "evidence": {
    "snapshot_url": "string | null",
    "video_clip_url": "string | null"
  }
}

Success

{
  "status": "accepted",
  "incident_id": "inc_123"
}

Errors

Invalid payload400
Wrong method405
Broadcast failure500

WS /handshake

Input: websocket upgrade. Output: accepted incident JSON messages.

Connect

wss://smart-wild.onrender.com/handshake

Message format

Same JSON object accepted by POST /alert.

GET /healthz

Input: none. Output: health JSON.

Request

GET /healthz

Response

{
  "status": "ok"
}

Validation

Unknown fields are rejected.
  • incident_id, occurred_at, reported_at, location.camera_id, and recommended_action.message are required.
  • type: animal_on_road, person_on_road, stopped_vehicle, road_obstruction, unknown.
  • recommended_action.priority: low, medium, high, critical.
